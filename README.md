# TP2: Teclado Predictivo 

Este proyecto implementa una estructura de datos dinámica modificada (`keysPredict`) en **C**. 
El objetivo es simular el funcionamiento de los antiguos teclados de celulares físicos, almacenando un diccionario de palabras de forma eficiente para predecir opciones a partir de un prefijo dado.

---

## Archivos del repo

* **`utils.c`**: Archivo principal donde se desarrolla toda la lógica de las estructuras de datos y funciones del sistema.
* **`utils.h`**: Cabeceras, prototipos de funciones y definiciones de las estructuras `keysPredict` y `node`.
* **`main.c`**: Suite de pruebas unitarias con los casos de test chicos y grandes requeridos.
* **`predict.c`**: Programa interactivo por línea de comandos para probar las predicciones usando el diccionario base.
* **`dicc.txt`**: Diccionario de texto con las palabras de soporte para el programa.
* **`Makefile`**: Script de automatización para compilar el proyecto fácilmente.
